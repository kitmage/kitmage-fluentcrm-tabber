Adds KitMage account-management tools to FluentCRM contact profiles.

== Description ==

The plugin adds the following tools to FluentCRM contact profiles:

* A Signatures section that links to signed WP E-Sign documents, searched using the contact's name.
* An Aspen Credits wallet widget linked to the contact's WordPress user ID.
* A Login As widget when the User Switching plugin is active and the current administrator can switch to the contact's WordPress user.

FluentCRM is required. WP E-Sign, the Aspen Credits wallet page, and User Switching are optional integrations used by their respective links and widgets.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate KitMage FluentCRM Tab Manager in the WordPress Plugins screen.
3. Open a contact in FluentCRM to use the profile section and widgets.
